# 栖伴 · 网页桌面伴侣 v0.6

在本目录运行 `npm start`，打开 http://127.0.0.1:5173/ 。需要 Node.js 18+。`dist` 是完整静态应用，模型和渲染库均为本地资源，不需要运行时 CDN。

## 三版走路效果

右上方人物视角区域新增“走路效果 · 03”。打开后可选择 **01 最初步态 / 02 上一版步态 / 03 轻松步态**，点击“走一段看看”播放当前效果，也可以直接点击地面移动。首次使用默认 03；之后记住上次选择。切换步态保留当前人物、工作室内容和场景。

| 版本 | 实现与变化 | 保留范围 |
| --- | --- | --- |
| 01 最初步态 | 恢复早期程序步态：较短的摆脚时间、追随身体的落脚目标、平脚、固定下蹲和独立摆臂相位。 | 从 v0.4 原方法源码恢复核心，适配当前可取消导航；不是完整旧版应用快照。放下资料动作是兼容当前工作室的补充。 |
| 02 上一版步态 | 保留 v0.5 的落脚、脚部 IK 与源动画混合效果。 | 原 `locomotion.js` / `avatar-body.js` 模块未改；改动前源码另存于 `motion-history/v2-20260922/`。 |

本轮浏览器验收使用用户已选的“未来感”人物，已实际切换并播放三种步态，人物选择保持不变。

## v0.5 升级记录（历史，现保留为 02）

- 上半身接入 Mesh2Motion 的 CC0 步行、持物行走和待机动画素材，按实际迈步相位采样；动作素材与手势通过渐变混合衔接。
- 脚部使用独立 Footwork 步态规划与两骨 IK：支撑脚保持地面锚点，另一只脚抬起、落下；加入脚尖蹬地、脚跟着地、双脚支撑间隔和转身换步。
- 行走先转向、逐渐起步、接近目标减速，双脚落稳后再执行手势；取消后收脚站稳，旧动作不会继续触发。
- 挥手、伸手、接收、放下、阅读和指向等手势使用程序关键帧，包含准备、执行和收回过程；放下时双手向前下方伸出，到松手阶段才释放道具，完整收回后再继续。

## 保留的工作室与桌面能力

- 接入第一张工作室方案：固定视角房间底图与实时 VRM 人物组合；项目柜、工作桌、任务白板和休息角关联实际操作。
- 右上角“经典桌面 / 进入工作室”随时切换，记住场景偏好；共用笔记、待办与导入文件，保留经典桌面图标位置和当前编辑内容。
- 柜子和显示器直接打开内容，白板显示前三条真实待办并可勾选，完整清单通过“管理待办”或底部“任务白板”打开。
- 点击“体验取资料”：人物到柜子取文件，携带到工作桌，最后走到白板旁。沿固定前景通道行走，支持停止和跳过；正常查看内容不等待动作完成。
- 工作室与经典桌面都支持单击空白处移动；工作室将目标投影到前景地面，途中再点会替换目标，点击控件不会误触自由移动。

- 三种可切换的真实 VRM 3D 人物：日常便装、温柔洋装、未来感。记住选择和大小；支持导入自己的 VRM（40 MB 内，仅本次页面生效）。
- 角色视线跟随、眨眼、呼吸、发丝物理、近景和转身；挥手、点头、伸懒腰、思考、伸手和接收动作。
- 用鞋底顶点校准模型接触地面的位置；三种内置模型沿用同一套步态和动作接口。
- 真实可保存的本地笔记、待办、TXT/MD 文件和全文搜索。刷新后保留内容、图标位置和人物偏好。
- 文件要点提取保留原文行号，可保存为笔记。输入上限为 1 MB / 20 万字符，按标题和条目提取，不是语言模型语义摘要。
- 多步骤指令、进度、停止、上一步撤销。否定指令不会误执行；冒号后的笔记正文不会被误当成新命令。
- 可选浏览器语音输入与系统语音播报；安静陪伴模式、称呼记忆。
- 原有图标拖放、双击、键盘打开、拖动窗口仍可用。还原图标位置不会删除笔记、文件或待办。

## 可试的指令

```text
记下：今天想到一个新点子！
添加待办：检查人物动作
完成待办：检查人物动作
搜索：灵感
提取要点，然后保存为笔记
整理桌面，然后打开待办
不要整理桌面
撤销
叫我：小林
安静陪我
伸个懒腰
```

自由内容作为当前指令余下的完整文本保存。例如“记下：先读书，然后休息”是一篇笔记，不会另行执行“休息”。

## 当前边界

桌面对象仍是网页模拟，尚未接入系统桌面控制或语言模型。自由聊天、情感理解、跨应用任务规划尚未实现。动作由已有动画素材、脚部 IK 和程序手势混合驱动；本版不包含完整衣物碰撞或真实物体抓取。工作室为 2.5D 合成：房间是固定视角生成图，人物为实时 3D，手持资料为透明纹理道具。家具没有真实 3D 碰撞体；以固定前景通道和家具站位约束行动，不支持绕到家具背面或任意旋转房间镜头。

笔记、文件、待办和偏好保存在此浏览器的本地存储；清理浏览器数据会清除内容，没有云同步。存储失败会提示并保留修改前状态。语音输入由浏览器决定是否可用，其语音服务可能联网；导入文本和 VRM 不上传。

## 代码入口与扩展

- `dist/character.js`：渲染、模型加载、移动与动作生命周期。保持模型米制比例。
- `dist/walk-styles.js`：三版步态定义、默认选择和速度配置。
- `dist/locomotion-v1.js` / `dist/avatar-body-v1.js`：恢复的 01 早期步态与身体公式。
- `dist/locomotion.js` / `dist/avatar-body.js`：保留不变的 02 步态与身体混合模块。
- `dist/locomotion-v3.js` / `dist/avatar-body-v3.js`：03 的髋部支撑规划、直立身体与放松手臂。
- `dist/two-bone-ik.js`、`dist/gesture-poses.js`：共用腿部 IK、程序手势关键帧与持物姿态。
- `dist/authored-motion.js`、`dist/assets/motions/`：本地 CC0 动画素材及标准人形骨骼旋转采样，不包含素材根位移。
- `dist/planner.js`：指令解析，输出结构化动作。未来语言模型应接到此边界，而不是直接操作 DOM。
- `dist/app.js`：可取消的动作编排、模型切换、语音及交互。
- `dist/studio.js`、`dist/studio-layout.js`、`dist/studio.css`：工作室数据热点、站位、可取消的表现动作与自适应构图。
- `dist/workspace-store.js`：本地持久化、写入失败原子性、内容撤销、原文提取。
- `dist/desktop.js`：模拟桌面和内容窗口；原生桌面版需要单独的系统适配器。
- `server.mjs`：只监听本地回环地址的静态服务。

`npm run check` 检查所有应用模块；本轮 `npm test` **90/90 通过**：能力与持久化 28 项、场景编排 24 项、上一版脚步 8 项、新版脚步 7 项、人物动作编排 9 项、源动画采样 5 项、新版上半身 9 项。测试验证动作状态与骨骼结果，不等同于视觉自然度验收。版本验证记录见 VERIFICATION.md；design-qa.md 保留 v0.4 工作室视觉对照。WebMCP 在支持的浏览器注册读取桌面及基础演示动作，读取结果包含场景和站位。
